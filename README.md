# telegram-resume-analyzer-bot
Telegram chatbot that analyzes Google Docs resumes using an AI agent and emails a detailed report via Make.com automation.

## ✨ Features

- Auto-triggered Telegram chatbot
- Accepts Google Docs resume link
- AI-based resume analysis
- Extracts email from resume
- Sends resume report via email
- Fully automated using Make.com

## 🛠️ Tech Stack

- Telegram Bot API
- Make.com (Integromat)
- AI Agent
- Google Docs
- Email Automation (SMTP / Gmail)
